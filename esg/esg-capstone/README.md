# ESG Capstone: Full Carbon Market Platform

**Skills:** `everything`

## Description

Build a complete carbon-credit marketplace. Actors: smallholder farmers (IoT → credit candidates), verifiers (NDVI + soil APIs), corporate buyers (web app), and an immutable QLDB registry.

Services: IoT Core, Kinesis, S3, Glue, Athena, QLDB, Lambda, API Gateway, CloudFront, Cognito, WAF, CloudFormation, CloudWatch. Multi-region (eu-west-1 primary, us-east-1 DR), full IaC, per-actor IAM roles.
