# ESG Reporting Platform on Azure

**Skills:** `data-factory`, `synapse`, `power-bi`

## Description

Many enterprises report ESG on Microsoft. Architecture: SAP/ERP export → Azure Data Factory → Synapse → Power BI.

Design the pipeline that ingests Scope 1/2/3 data, applies the GHG Protocol methodology, and outputs a board-ready report. Bonus: connect Microsoft Sustainability Manager.
