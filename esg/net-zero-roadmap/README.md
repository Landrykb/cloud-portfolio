# Net-Zero, Carbon Neutral & Science-Based Targets

**Skills:** `net-zero`, `sbti`, `scope-1-2-3`

## Description

Net-Zero is not the same as Carbon Neutral.

- **Scope 1:** direct emissions (your factory, fleet).
- **Scope 2:** indirect from purchased electricity.
- **Scope 3:** everything else (supply chain, travel, customers).

The Science-Based Targets initiative (SBTi) certifies corporate net-zero plans. Learn what a real roadmap looks like so you can architect the systems that track it.
