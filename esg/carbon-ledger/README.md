# Carbon Credit Ledger: Database or Blockchain?

**Skills:** `dynamodb`, `qldb`, `immutability`, `audit-trail`

## Description

Carbon credits need immutable, auditable records. Two AWS options: (1) DynamoDB with strict versioning, or (2) Amazon QLDB — a managed ledger DB with a cryptographically verifiable journal.

Build the data layer for a marketplace where farmers list verified credits, corporates purchase and retire them, and every transaction is permanently recorded.
